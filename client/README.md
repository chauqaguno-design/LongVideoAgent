# CutSieve 前端

Vue 3 / Vite 客户端包含媒体库、分析工作台与 Pixel Future Academy 设计实验室。完整产品介绍和后端启动步骤见 [根目录 README](../README.md) 与 [本地快速开始](../docs/QUICK_START.md)。

```bash
npm ci
npm run dev
```

开发代理默认指向 `http://127.0.0.1:8000`；更改后端地址可设置 `CUTSIEVE_DEV_PROXY_TARGET`。独立部署前端时可设置 `VITE_API_BASE_URL`。测试与构建命令是 `npm test`、`npm run build`。

首页和 `/#edit` 默认打开视频工作台的「对话与任务」。创建素材项目，在「素材处理」上传视频或从媒体库导入，然后返回对话选择一部视频。手动剪辑仍可从「时间线」进入。原片区间以秒输入，支持最多六位小数。预览和导出记录保存在各自的时间线版本下。

在「素材处理」可以查看每次任务的阶段、缺口、画面分析用量，以及包含台词和画面证据的观影笔记。点时间戳会定位到原片。暂停大文件上传后，重新选择同一文件可以续传。

在「检索片段」输入台词，或上传截图并选择要搜索的像素区域。点击候选可回看来源、检查依据或添加到当前剪辑。勾选「按台词原文核查」，再选「统计次数」和「按本次查询核查原片」，可以在「对话与任务」查看有证据的匹配和核查范围。

在「对话与任务」可以先问“哪一段说了「Ticket」？”，回看编号候选，再发“把刚才第二段剪出来”，然后发“前面再留两秒，然后导出”。每轮保留问题、任务计划、候选和回答。澄清后可以继续原任务。结果支持回看原片、播放固定版本预览与下载 MP4。刷新或打开任务深链可以恢复最近 20 轮。切换影片或点击「新对话」会开启独立上下文。在「时间线」可为片段选择已对齐字幕，输出时保留独立字幕轨或烧录进画面。

组件测试运行 `npm run test:components`。浏览器验收使用隔离的本地 API 和前端，注册一次性账号，验证上传、两段剪辑、改序、刷新恢复、成片播放与 MP4 下载。设置 `CUTSIEVE_EDIT_SAMPLE` 为不少于四秒的视频文件路径，`CUTSIEVE_EDIT_UI` 为本地前端地址（默认 `http://127.0.0.1:5175`），运行 `npm run test:e2e:edit`。Windows 使用本机 Edge，其他平台可用 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定 Chromium 可执行文件。

`/design-lab` 只展示设计示例，不访问后端。架构说明见 [ARCHITECTURE.md](../docs/ARCHITECTURE.md)，上游改编声明见 [NOTICE.md](NOTICE.md)。

使用仅限回环地址的 `CUTSIEVE_EDIT_UI` 运行 `npm run test:e2e:conversation` 可以验收连续对话。这项测试使用 FFmpeg 生成有两处相同台词的六秒素材，通过独立浏览器会话实际完成查询、澄清、预览、导出、刷新和新对话。可设置 `CUTSIEVE_EDIT_EVIDENCE` 保存桌面与移动端截图和实测记录。
