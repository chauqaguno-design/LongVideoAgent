# ReelCue 架构

ReelCue 是本地优先的视频检索与剪辑工作台。Vue 3 和 Vite 提供界面，FastAPI 提供 HTTP API。本地模式运行一个 API 进程，由它启动素材处理、工作流、渲染和事件投递循环。

## 存储与检索

- **SQLite** 保存账号、项目、素材与索引版本、对话检查点、时间线和任务状态。默认数据根目录是 `work/r1-media`。
- **本地文件** 保存原片、处理产物、预览和成片。FFprobe 读取媒体信息，FFmpeg 提取素材并渲染输出。
- **Qdrant** 为已配置本地编码器的工作台提供向量索引，可使用嵌入式目录或 HTTP 服务。词法检索可独立查询已提取的字幕和转写。

## 从素材到成片

1. 上传完成后，后台处理为原片版本生成带时间戳的证据和覆盖记录。已启用的字幕、转写、OCR 和画面处理各自记录实际覆盖范围。
2. 检索限定在当前工作区、项目、原片版本和已发布的索引中。候选结果保留可回看的原片区间。查询首次出现或总次数时，结果会报告实际核查范围。
3. 单一协调器推进规划、选材、剪辑和复核。工作循环每次领取一个阶段并持久化检查点。需要用户确认候选时，任务暂停并等待输入。
4. 每次提交的剪辑生成时间线版本。FFmpeg 按指定版本生成预览或成片，记录原片区间与输出时间的对应关系。

启动后端、前端和可选的向量检索服务，见[本地快速开始](QUICK_START.md)。
