# 002 — 实施计划

## 1. 架构与输入输出

复用既有 ASR/OCR/embedding 服务并增加能力适配层，不在业务 service 中散落供应商 SDK。统一能力接口接收受控 Artifact/源范围及版本配置，返回规范结果与供应商元数据；调用者不能提供任意磁盘路径、远程 URL 或租户身份。

| 适配器 | 最低能力声明 | 规范输出 |
|---|---|---|
| ASR | 格式、语言、最大块、时间粒度、声道、VAD、对齐支持 | 源范围、文字、时间精度、质量标记、原始响应 artifact |
| OCR | 图像/ROI 输入、坐标系、语言、检测与识别支持 | 文字框/原图坐标、可读性、识别来源 |
| Flash observer | 图片输入、结构化输出、工具调用、resolved model | Observation 候选、输入证据引用、usage |
| Text encoder | BGE-M3 版本、维度、前缀、最大输入、归一化 | 稳定向量与空间标识 |
| Image encoder | 图图/图文能力、语言、维度、预处理、可选 ROI | 与索引一致的查询/帧向量 |
| Clip encoder（可选） | 有序帧输入、时间处理与顺序敏感性 | 片段候选向量，不直接输出事实证据 |

不能因为 SDK 兼容 OpenAI 格式就推断存在 embeddings endpoint。Flash provider 的图片和工具测试由 M0/004 共用，未通过真实合同测试时此路 BLOCKED，不调用 Pro 或另一通用模型替代。

## 2. 源记录与私有元数据

公开 Observation/Evidence、Segment、SemanticEvent 与 Summary 严格遵守统一 schema。新增内部表或 artifact metadata 记录词级对齐、OCR bounding boxes、对象与动作候选、summary child references、依赖 hash、encoder space descriptor 和 quality assessment。每条关联都校验同一 workspace、project 与 media_revision；公开 Summary 为单媒体层级摘要。跨媒体问答汇总使用 AnswerResult 或 REPORT artifact，各项证据分别保留自己的媒体与 source range，不把不同媒体拼成单一 Summary 时间轴。

10秒片段不一定命中60秒概览采样帧；没有视觉输入时Segment.visual_status=UNOBSERVED，不能从邻段复制caption。图像检索可用独立embedding预算补片段中心锚点，复用重复PTS帧；这些额外帧只属于DECODED/图像索引能力，未经Flash读取不得升级为MODEL_OBSERVED。具体策略见docs/04_MEDIA_RETRIEVAL.md。

事件与摘要可复用现有领域表；若无，则作为带类型的派生产物及关系表实现，不强行改统一公开实体名称。摘要的章节范围不是根据视觉聚类簇顺序硬拼出来；无连续时间关系的相似场景应作为主题引用，不标成连续章节。

质量标记至少覆盖：ASR 时间粒度不足、低语音支持、重复待核查、音轨/字幕冲突、OCR 不可读、画面顺序未核查、身份不确定、部分覆盖。标记不是自动删除规则。

## 3. 音频处理算法

1. 读取 001 的音频流元数据与源映射，选择经过验证的下混/声道策略。
2. 按 provider 限制切块；保留核心区间与必要重叠上下文，块大小与重叠进入版本配置。不能把当前某厂商的 120 秒限制硬写成通用业务语义。
3. 执行 VAD/声学量测并保留候选；根据检测不确定性决定正常转写、复转写或人工回听路径，不以单阈值禁止转写。
4. ASR 转写后转换时间至源微秒；对越界、负时长、逆序段、空字符串、超长重复做结构与质量检查。
5. 重叠去重依据源时间和音频实例对齐；相邻块的重复边缘可合并，同文字的非重叠真实实例保留。
6. 若缺词/句时间且后续确需字幕/句级剪辑，运行专用对齐并标明版本；若失败，保持段级结果，不伪造精度。
7. 只在观察提交后推进相应覆盖；没有语音的检测结果以处理与覆盖记录表达，不生成虚假“说话内容”。

使用 DeepSeek 同厂商 ASR 时同样走专用适配器；它是独立接口，不归属于 model=deepseek-flash 的原生能力。接口只返回 text/duration 时，不自动宣称已具备句级时间戳。

## 4. 画面文字与 Flash 观察

### 4.1 原图文字

概览只决定需要精读的区域。OCR 从实际 FrameArtifact 的原始分辨率裁图，保存 ROI 与缩放/旋转变换。首版可复用本地专用 OCR；Flash 对高价值或冲突区域进行读字复核。两者的输出来源字段不同，不能把一般 caption 中的文字猜测当作经过 OCR 的原文。

同一屏幕文字跨相邻帧重复时可以归并其出现区间，但必须保留改变点附近证据。文本归并不能只做字符串相似而忽略时间；真实重复字幕应是多个发生实例。文字框被裁断、压缩模糊或缩放后不可读，返回 UNCERTAIN。

### 4.2 结构化视觉观察

按 60 秒窗口公平安排模型观察；每次输入若干有序帧/局部帧组，附 frame artifact ID、actual_us 和允许引用的源范围。模型收到的媒体正文明确标为不可信数据；工具权限与系统指令在应用端隔离。

输出 schema 至少覆盖可见实体/关系、候选动作、文本需要精读的区域、无法确认的问题、源 frame IDs 和 OBSERVED/INFERRED。应用将有效原子描述映射为合同 Observation；供应商原始结构存入受控 artifact。

校验流程为：JSON/schema → 输入ID白名单 → 归属/时间范围 → 单帧与时序主张一致性 → 质量标记 → 持久提交。schema 错误允许至多配置内的修复次数；错误响应不能进入索引。空白或无有效内容是有效失败/无观察结果，而不是强行补一段泛化描述。

## 5. 事件归并与层级记忆

默认以 10 秒/2 秒重叠 Segment 汇集各模态证据；以镜头、语句和活动边界形成更高层连续段，再由 Flash 生成章节与全片摘要。摘要必须返回 child evidence IDs 与不确定项，服务端验证每项引用。

同一事件的归并候选先用源时间重叠筛选，再比较动作和参与实体；“同一个发生实例”作为归并单位。事件文本相似不能作为唯一条件。跨段关系分为有证据支持与待验证，不进行未经验证的跨镜头 ReID。需要“同一个人全片做了什么”时由 003 返回限制或触发后续身份关联功能。

每个摘要的依赖 hash 包括子证据集合/版本、范围、覆盖、prompt 与 resolved model。任何依赖变化使该摘要和其向量失效。模型上下文使用摘要与证据 ID，原始观察保留在数据库/对象存储；不能只靠会话压缩保存业务事实。

## 6. 文本与图像 embedding

### 6.1 文本路

复用现有 BGE-M3，在 M0 核实真实 checkpoint、维度、最大输入、归一化、dense/sparse 能力和客户端输出。不要在未核实前编造这些配置。ASR/OCR/caption/摘要使用明确 modality 与来源 ID，避免把相同文本复制多次后靠票数提高排名。

长文本按语义与时间边界分块；保留覆盖原文 offsets 与源范围，不能在 embedding 截断后仍声称全部内容已编码。查询和文档前缀策略固定在 embedding_space_id 中。词法与向量使用同一 generation、权限与源版本过滤。

### 6.2 图像路与选型 ADR

首版选型必须交付 ADR：候选许可证、部署成本、输入规格、图图能力、是否支持中英图文、维度、归一化、预处理、开发集 Recall、查询耗时。未经基准不在生产配置中固定一个新模型名称或维度。

FrameArtifact 原图/标准化图的 embedding 生成和查询截图必须共享 encoder 与预处理。允许同时保存 full-frame 与 ROI 向量，但 payload 中应区分，结果映射回原图坐标和实际源时间。截图中 OCR 文本可以额外检索，不能用于冒充图像路完成。

不同 checkpoint、维度、归一化或 crop 策略的向量不能混在同一空间。即使维度相同也不兼容。构建适配器在写入与查询两侧检查 space descriptor，错误应 fail closed 并给出重建/配置指引。

### 6.3 可选片段表示

先用图像/文本候选召回加 Flash 连续帧复核完成产品。只有动作型查询基准暴露明确召回缺口时才引入视频 encoder。必须进行帧顺序打乱/反转对照，验证其序列表征性质；不把图像 embedding 均值叫作时序理解。它的输出仍是候选，精确边界由 003 验证。

## 7. 构建、失效与发布

cache key 使用媒体 digest、输入 artifact hashes、时间与帧顺序、ROI/预处理、provider resolved version、prompt/schema/pipeline/encoder 版本。缓存按 workspace 授权读取；底层内容相同不表示允许跨租户直接返回 artifact。

构建一个 IndexGeneration 的全部 manifest 组件，包括文本/词法、图像、摘要依赖、覆盖和显式缺失能力。Qdrant 记录先写 BUILDING 隔离区，每条 payload 含 workspace/project/media_revision/generation 和来源 ID。

回验包括数量、非空/有限向量、维度、归一化配置、随机读取、来源存在、ACL payload、版本一致、删除 tombstone、覆盖清单。满足声明目标后由 T01-009 协调器发布；部分能力发布必须显式列明缺失，不能将 image_embedding FAILED 标成可截图搜索。

更新 caption 只重建相关视觉文本/摘要/文本向量；更新图像 encoder 重建图像空间，不必重新 ASR；更新媒体 bytes 创建新 revision 并重建相应链。ACTIVE 记录不原地改写。删除优先阻断可见性，再按引用关系回收旧观察、缓存和向量。

## 8. 验证

拟建立 tests/multimodal_memory 的 adapter/schema/质量/归并/缓存/索引测试，并在开发集跑真实能力。标注原文、事件与时序由人工或有确定真值的合成媒体提供；不让被测 Flash 同时生成唯一真值。

必须覆盖：真实重复台词、纯 BGM 的错误转写、音乐叠人声、左右声道差异、字幕/音频冲突、低对比度小字、单帧错误时序主张、跨块事件、提示注入、错维度/错空间向量、重建时查询和权限撤销。中文/英文/混合、运动/低运动、长片末段分别统计。

最终检索质量按 003 的独立盲测门槛，不以 embedding 生成成功或模型返回非空为质量通过。实际调用记录费用与吞吐；未能真实调用的适配器在验收中标 BLOCKED。
