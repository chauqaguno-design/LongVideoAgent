# VideoMind 开发协作说明

本文件是规范包中的目标仓库协作模板。接入已有仓库时先读取既有AGENTS并增量合并，不覆盖原文，也不覆盖更高优先级指令。

- 开始任务前读README、constitution、当前feature spec/plan/tasks、contracts和PROGRESS。
- 通用模型只使用DeepSeek Flash；专用ASR/OCR/embedding/FFmpeg独立。
- 需求、任务、验收分别使用REQ、T、AT编号，状态和证据保持可追踪。
- 对现有VideoMind做增量改造，优先复用框架、存储、认证、队列和前端。
- 模型只调用受控工具；权限、参数、预算和副作用在服务端执行。
- 原媒体不可变；源区间为整数微秒半开区间；保留真实PTS，输出时间线另算。
- 处理覆盖、模型观察和查询验证分开记录；不承诺稀疏采样语义零漏检。
- 时间线修改使用CAS和幂等键；渲染固定revision；队列按至少一次投递处理。
- 产物必须实际生成并校验。mock、离线测试、真实服务验收分别标记。
- 每完成一个任务更新PROGRESS、AT证据和task状态；失败要说明原因，不能删除测试过关。
- 遵守环境权限与用户授权；常规可逆实现持续推进，真正阻塞记录清楚。
