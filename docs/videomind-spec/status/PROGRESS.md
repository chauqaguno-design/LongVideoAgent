## 可以直接操作

在工作台上传视频，查看每个处理阶段、缺口和观影笔记。台词、OCR、内嵌字幕和采样画面保存独立来源。可以输入台词、描述，或上传截图并限定区域。候选可回看原片、检查依据、加入剪辑。选择「核查」会创建可恢复的工作流。全局检索返回匹配清单及核查范围。选择「按描述剪辑」可以指定台词或原片区间，试播、修改、恢复历史版本并导出。输出支持原声、静音、裁切、独立字幕或烧录字幕。

## 实际走过的链路

| 验证材料 | 操作与结果 |
|---|---|
| 桌面 15 秒电影样片 | Whisper 转写了 7 处台词。“Wait a minute.” 定位在 8.90–9.26 秒，按这句台词导出 0.36 秒原声。浏览器实测台词回看停在 8.900 秒，截图回看停在 5.600 秒。另用“剪出第 1 到 3 秒并导出”下载 644,370 字节的 MP4，SHA-256 与服务端回执相同。 |
| 两小时可复算素材 | 稀疏片源实际解码并核对片尾。含测试字幕的副本定位到 01:59:30–01:59:32 的台词，01:59:00 的黄色截图与源帧逐像素相符。先预览首尾两段，再裁短、调换次序，导出 3.52 秒。下载文件逐帧抽查先黄后黑。过期写得到 409，SSE 断线后连续补回 14 条事件。该片专门用于检查长时轴。 |
| 原图文字与声音 | 画面写“请把钥匙放在桌上”，原声说“Open the yellow door.”。本地 OCR 和 ASR 在两种字号下均保留各自原文、区间及来源。65 秒立体声样片中，语音和音乐分布在不同声道，同一英文口令在 0.72–2.04 秒与 59.12–60.02 秒分别保留。 |
| 文字与图像向量 | 使用真实 BGE-M3 和 Qwen 视觉向量，在测试样本中中英台词三次、变换截图三次均排在首位。另起 MySQL 和 Qdrant 服务，检验发布期间旧查询固定原代次，新请求读取新代次；更近的无权候选在排序前被排除。 |
| 相邻画面对照 | 又从同一电影样片的 4 个镜头抽取 20 个候选帧。12 次裁切、压缩或两者组合后，排第一的结果都属于正确镜头，其中 2 次正好是原帧，其余是该镜头内的邻帧。这组数据只说明已测样片能定位到镜头。 |
| 编辑、故障与恢复 | FFmpeg 对固定/可变帧率、非零源 PTS、旋转、无音轨及跨剪点字幕做实际编码和解码。真实 RabbitMQ 重启、未确认消息重投和 SQL inbox 去重均已测试。MySQL 迁移回退后再升级，从独立数据库、对象桶和空缓存登录，取回旧成片并重新导出。 |
| 组合剪辑要求 | 输入“总时长 2 秒、保留讲话、包含字幕 Ticket、排除字幕 spoiler”，从三处命中中选出 2–3 秒和 3–4 秒，成功导出并核对原声。将时长改为 4 秒，界面显示冲突并等待补充。[实测记录](../../development/evidence/dialogue-brief.json) |
| 故意剪错的成片 | 同一时间线导出四个可播放文件。剪反事件顺序时结构通过，真实帧的受控语义检查发现冲突；字幕晚一秒和缺少必要音轨均由结构检查发现。两项检查都记录所验成片的 SHA-256。[实测记录](../../development/evidence/render-quality.json) |

## 性能和费用

在 1 万条已建索引的本地测试记录上，词法混合检索 P50 为 0.53 秒，P95 为 0.67 秒。10 并发下，任务受理 P95 为 0.16 秒。计时包括本次测试使用的接口调用，不包含上传、媒体解码、模型复核及渲染。上述样片验证使用本机模型，外部模型调用为 0 次，在线 API 费用为 0 元。[原始基准](../../../work/spec-evidence/search/benchmark-10k.json)

## 当前验收边界

- 默认 Python 回归 2,054 项通过，56 项跳过。另起真实服务的历史集成回归 114 项全部通过。前端 112 项单元测试、13 项组件测试和生产构建通过。安装包也在独立 Python 环境中启动，加载了接口合同和数据库迁移。运行套件之间有重叠，数字分别记录。[运行结果](../../development/verification.json)
- **本地真实集成**覆盖媒体处理与恢复、独立索引空间、范围过滤、台词与截图检索、工作流恢复、可重试剪辑、渲染和文件回读。默认单 Agent 可以在本地用明确台词或时间范围完成这些任务。
- **受控适配器验证**覆盖结构化画面观察、原生与 JSON 工具交互、有限修复、按角色授权、计费预留和不确定费用。Team 与在线模型开关默认关闭。影片中人物的身份、动作先后和复杂叙事需要相应的视觉与声音证据。
- **待真实服务配置**的是指定 Flash 部署的图片理解、工具往返与实际费用。该部署的真实付费验证按用户选择延期。
- **待独立盲测**的是文本与截图召回率、动作边界、证据精度和全片计数。仍须至少 24 条视频、12 小时、320 条独立人工查询及其真值；正式分组和精度门槛见[发布规范](../docs/08_VERIFICATION_RELEASE.md)。
